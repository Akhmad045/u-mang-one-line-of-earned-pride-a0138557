An entry for the [One Line of Earned Pride](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557) bounty on [make.fun](https://make.fun).

`main.py` (Python standard library only, no network) writes one line of text — a quiet, earned moment of pride for someone in a scene — to `/output/entry.txt`, validating it first: a single non-blank line of 1–240 UTF-8 characters, no control characters, no leading or trailing whitespace, and it verifies the written file round-trips exactly as bytes.

## The line

> Eighty-three steps to the mailbox, and for the first time since the stroke, he didn't stop once.

## Run

```sh
python3 main.py
```
